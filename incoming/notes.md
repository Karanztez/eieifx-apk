# บันทึกการอัปเดต eieiFX (Release Notes)

## 🌟 เวอร์ชันล่าสุด (1.0.182)

### ✨ ไฮไลท์การอัปเดตล่าสุด

- 🤖 **OpenAI Multi-Agent Swarm Architecture (3 เลเยอร์)**: สถาปัตยกรรมตัวแทนอัจฉริยะ 4 บทบาท (Architect, RAG Knowledge, Geometry Engineer, Game Bridge) ประสานงานและส่งมอบงานแบบเรียลไทม์
- 🧠 **เชื่อมต่อ Local LLM & Strict JSON Schema**: รองรับการเชื่อมต่อ Ollama (`Qwen 2.5 Coder 14B/32B`, `DeepSeek`), vLLM, OpenAI API พร้อมระบบคุมโครงสร้างข้อมูล Coordinate แบบเข้มงวด
- 📚 **Minecraft & Blockbench Vector RAG System**: คลังความรู้สเปกไฟล์ `.bbmodel` 4.10, Bedrock `geometry.json`, Minecraft 1.20+ `item_display` NBT matrix และกฎ Box UV 6 ด้าน ป้องกันการหลอนของ AI
- 🎮 **Game Bridge & Code-to-Asset Pipeline**: สร้างคำสั่ง In-Game `/summon item_display`, `/setblock`, สคริปต์บอต Mineflayer (Voyager-style), ซอร์สโค้ด Paper Java และ LeviLamina C++ ได้ในคลิกเดียว
- 🗺️ **กาง Minecraft Box UV แท้**: คำนวณพิกัด UV หน้ากล่องจริงทุกชิ้นส่วน ไม่ทับซ้อน พร้อมนำไประบายสีใน Blockbench ได้สมบูรณ์แบบ
