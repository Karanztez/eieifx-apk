## 📦 ประวัติเวอร์ชันก่อนหน้า

### เวอร์ชัน 1.0.121

- **แก้ไขปัญหา Action 1 ค้างเล่นต่อเนื่องและ Action 2 ซ้อนทับกัน (Action Step Isolation & Smooth Transition)**:
  - **ปรับแต่ง Step Animations ใน Bedrock Add-on ให้เป็น `loop: false`**:
    - ใน Minecraft Bedrock แต่ละสเต็ปแอนิเมชั่นจะเล่นเพียง 1 รอบตามระยะเวลาของตัวเอง (`animation_length: stepDur`) ไม่วนลูปค้างอยู่ใน Animation Controller
    - เมื่อ Animation Controller สลับ State ไปยัง Action 2 เอนจิ้นจะตัดการทำงานของ Action 1 ออกอย่างสมบูรณ์
  - **บังคับซ่อนกระดูก (`scale: [0, 0, 0]`) สำหรับเลเยอร์ที่ไม่ได้เปิดใช้งานในสเต็ปนั้น**:
    - เลเยอร์ใดที่ไม่ได้ปรากฏในสเต็ปนั้น หรือถูกซ่อนไว้ จะถูกเขียนคีย์เฟรม Scale เป็น `0.0` ทันทีตั้งแต่จุดเริ่มต้นจนจบสเต็ป ป้องกันไม่ให้แอนิเมชั่น Procedural (เช่น Spin, Pulse) หรือ Action Skill Keyframes ของ Action 1 ค้างเล่นซ้อนใน Action 2
  - **ปรับปรุง Transition Mode ใน Studio Viewport ให้สมูทไม่ซ้อนกัน**:
    - แก้ไขตรรกะเดิมที่เฉลี่ยเวลากลางสเต็ป (`t < 0.5` / `t > 0.5`) ซึ่งทำให้ Action 2 เริ่มโผล่มาทับตั้งแต่ช่วงกลางของ Action 1
    - ปรับเป็นระบบ Hand-off Transition Window เฉพาะช่วงท้ายของสเต็ป (15% สุดท้าย): ช่วงตัวสเต็ป Action 1 จะเล่นสมบูรณ์ 100% เต็มที่ แล้วค่อยส่งต่อให้อีกสเต็ปทำงานต่ออย่างราบรื่น
  - **คำนวณเวลาแอนิเมชั่นตามเวลาของสเต็ปปัจจุบัน (`stepElapsed`)**:
    - ใน Studio Viewport การเล่นแอนิเมชั่น Procedural และคีย์เฟรม Action Skill จะใช้เวลาเริ่มนับจาก 0 ของแต่ละสเต็ป ทำให้เมื่อสลับสเต็ป แอนิเมชั่นของสเต็ปใหม่จะเริ่มเล่นจากจุดเริ่มต้นอย่างถูกต้อง

- **แก้ไขปัญหาเอฟเฟคชั้นหลักและชั้นย่อยมองเห็นแค่ด้านเดียว (Double-Sided & Multi-Angle Visibility Fix)**:
  - **สร้างไฟล์ Material แบบ Double-Sided (`materials/entity.material`) ใน Bedrock Resource Pack**:
    - เพิ่มไฟล์ `materials/entity.material` บรรจุ Custom Material `eieifx_vfx` และ `eieifx_vfx_glow` ที่ระบุ State `"DisableCulling"` และ `"Blending"`
    - ปิดการทำงานของ GPU Backface Culling ใน Minecraft Bedrock ทำให้แผ่นระนาบเอฟเฟค 2D ทั้งหมด (Stamps, Crescents, Slashes, Wings, Discs) มองเห็นได้ทั้ง 2 ด้านจากทุกทิศทาง 360 องศา ไม่หายไปเมื่อมองจากด้านหลัง
  - **สืบทอดค่าทิศทาง (Multi-Direction) และ Parallel FX จากชั้นหลักสู่ชั้นย่อย (Sub-Layer)**:
    - ชั้นย่อย (Child Layer) จะสืบทอดค่า `directionCount`, `directionLayout`, และ `parallel` จากชั้นแม่ (Parent Layer) โดยอัตโนมัติ
    - ทำให้เมื่อชั้นแม่มี 2 ด้านตรงข้าม หรือ 4 ทิศกากบาท ชั้นย่อยจะถูกเรนเดอร์ในทุกทิศทางและทุกมุมมองเหมือนกับชั้นหลักอย่างสมบูรณ์แบบ
  - **เชื่อมต่อกระดูกชั้นย่อยเข้ากับกระดูกชั้นแม่ตรงตามทิศทาง**:
    - ในไฟล์โมเดล `geometry.json` และ `.bbmodel` กระดูกของชั้นย่อยในแต่ละทิศทางจะต่อเป็นลูกของกระดูกชั้นแม่ในทิศทางเดียวกัน ทำให้หมุนและเคลื่อนไหวตามกันอย่างถูกต้องในทุกมุมมอง

## 📦 ประวัติเวอร์ชันก่อนหน้า

### เวอร์ชัน 1.0.116
  - **เปลี่ยนรูปแบบ Bone Rotation จาก Keyframe Timeline เป็น Direct MoLang Array**:
    - ใน Minecraft Bedrock Animation เมื่อใส่ค่าเป็น Keyframe Object เช่น `"rotation": { "0.00": ["query.camera_rotation(0)", ...], "1.00": [...] }` เอนจิ้นของ Bedrock จะพยายาม Interpolate ตัวเลข แต่เมื่อพบว่าข้างในเป็น MoLang String จะทำให้เอนจิ้นปฏิเสธหรือรีเซ็ตค่าเป็น `[0, 0, 0]` ส่งผลให้ชิ้นงานหยุดนิ่งไม่หมุนตามกล้องเลย
    - ปรับปรุงให้ Billboard Layer ส่งออกเป็น **Direct Continuous Array** ลงที่ `bone.rotation` โดยตรง:
      ```json
      "rotation": [
        "query.camera_rotation(0)",
        "(query.camera_rotation(1) - query.body_y_rotation)",
        0.0
      ]
      ```
      ทำให้เอนจิ้น Bedrock คำนวณมุมกล้องใหม่ทุกๆ Tick/Render Frame (60 FPS) แบบ Real-time ไม่ว่าจะหมุนกล้องไปทางไหน แผ่นเอฟเฟคจะหันหน้าประจันหน้าเข้าหากล้องตลอดเวลา 100%
  - **ปรับแต่ง Rest Pose ใน Geometry สำหรับ Billboard Bones**:
    - ในไฟล์ `geometry.json` กำหนดให้กระดูกที่เป็น Billboard มี Rest Pose เป็น `[0, 0, layer.rotation[2]]` โดยเคลียร์ค่า Pitch และ Yaw เริ่มต้นให้เป็น `0`
    - ทำให้สูตร MoLang ใน Animation ไม่ต้องหักลบ Offset ซับซ้อน และไม่เกิดปัญหาการบิดเบี้ยวของเมทริกซ์ Euler Angles
  - **อัปเกรด Animation Schema Version เป็น `"1.10.0"`**:
    - เปลี่ยน `format_version` ในไฟล์ Animation จาก `"1.8.0"` เป็น `"1.10.0"` เพื่อให้รองรับ `query.camera_rotation(0)` และ `query.camera_rotation(1)` ตามสเปกทางการของ Bedrock เต็มรูปแบบ
  - **ลบแผ่นไขว้ 90 องศา (Cross-Plane) ที่ไม่จำเป็นออก**:

  - ☁️ **เมฆเกียร์ 5 (`gear_cloud`)**: ปอยเมฆควันเทพนิกะฟูนุ่มโอบรอบตัว
