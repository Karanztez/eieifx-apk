# บันทึกการอัปเดต eieiFX (Release Notes)

## 🌟 เวอร์ชันล่าสุด (1.0.181)

### ✨ ไฮไลท์การอัปเดตล่าสุด

- ☁️ **Cloud AI Engine เชื่อมโยงระบบสมองกล**: เพิ่มการเชื่อมต่อไปยัง AI Cloud Engine เพื่อค้นคว้าและสังเคราะห์สรีระกายวิภาค 3 มิติอย่างแม่นยำ ลุ่มลึก และเป็นธรรมชาติ
- 🐉 **สมองกลกายวิภาคสัตว์และมังกรระดับสูง**: ปรับปรุงโครงสร้างสรีระมังกรและสัตว์ในตำนาน คอเรียวยาวทรงพลัง ปากขากรรไกรประกบสมจริง ปีกกว้างพร้อมพังผืด 2D หางโค้งสลับข้อ และกรงเล็บระนาบพื้นสมบูรณ์แบบ
- 🔥 **ระบบจัดเฉดสีอัตโนมัติตามอัตลักษณ์ (Adaptive Magma & Element Palette)**: AI ตรวจสอบและคัดเลือกพาเลทสีที่เข้ากับบริบท เช่น มังกรไฟสีแดงเพลิง-ส้มลาวา-ทอง ไม่สับสนกับโทนสีอื่น
- 📱 **ปรับแต่ง UI ช่องแชทมือถือ คลีนและโล่งตา**: ซ่อนแถบสถานะและข้อความช่วยเหลือที่บดบังหน้าจอ ให้พื้นที่มุมมองโมเดล 3D และกล่องข้อความพิมพ์ถนัดมือ ไม่กินพื้นที่หน้าจอ
- 🗺️ **กาง Minecraft Box UV แท้**: คำนวณพิกัด UV หน้ากล่องจริงทุกชิ้นส่วน ไม่ทับซ้อน พร้อมนำไประบายสีใน Blockbench ได้สมบูรณ์แบบ
