# บันทึกการอัปเดต eieiFX (Release Notes)

## 🌟 เวอร์ชันล่าสุด (1.0.150)

### ✨ ไฮไลท์การอัปเดตล่าสุด

- 🔒 **ยกระดับระบบสมัครสมาชิกและความปลอดภัยของบัญชี (Enhanced Account Security)**:
  - กำหนดมาตรฐานชื่อผู้ใช้ (Username) ความยาว 6 - 12 ตัวอักษร เพื่อความเป็นระเบียบและปลอดภัย
  - ระบบตรวจสอบความถูกต้องของรูปแบบอีเมล
  - ยกระดับมาตรฐานรหัสผ่าน ความยาว 6 - 12 ตัวอักษร ผสมตัวอักษรภาษาอังกฤษและเครื่องหมาย (`.` หรือ `_`)
  - เข้ารหัสผ่านอย่างปลอดภัยด้วยมาตรฐาน SHA-256 ก่อนบันทึกลงสู่ฐานข้อมูล MongoDB
  - เพิ่มป้ายสถานะตรวจสอบความถูกต้องของรหัสผ่านแบบเรียลไทม์ ช่วยให้ผู้ใช้ทราบเงื่อนไขทันทีขณะพิมพ์

- ☁️ **ระบบคลาวด์สตูดิโออัตโนมัติ (Automated Cloud Sync)**:
  - เชื่อมโยงและบันทึกแบบร่าง VFX ขึ้นระบบคลาวด์อัตโนมัติในเบื้องหลัง
  - ซ่อนข้อมูลทางเทคนิคออกจากหน้าจอทั้งหมด เพื่อความปลอดภัยและความเป็นมืออาชีพ

- 🚀 **ระบบซิงค์อัปเดตอัตโนมัติ (CI/CD Auto-Deploy)**:
  - เชื่อมโยงระบบเซิร์ฟเวอร์เข้ากับ GitHub อัตโนมัติ ซิงค์ข้อมูลเบื้องหลังทันทีเมื่อมีการอัปเดต

- 📱 **รองรับการใช้งานข้ามแพลตฟอร์ม (Cross-Platform Ready)**:
  - ทำงานได้อย่างสมบูรณ์แบบทั้งบน Android (APK) และ Windows (.exe)
