# บันทึกการอัปเดต eieiFX (Release Notes)

## 🌟 เวอร์ชันล่าสุด (1.0.149)

### ✨ ไฮไลท์การอัปเดตล่าสุด

- 🔒 **ระบบบัญชีผู้ใช้และการเข้าสู่ระบบ (Mandatory User Authentication)**:
  - เพิ่มระบบสมัครสมาชิกและเข้าสู่ระบบ เพื่อความปลอดภัยและการปกป้องสิทธิ์การเข้าถึงสตูดิโอ
  - บังคับการเข้าสู่ระบบผ่านบัญชีก่อนเข้าใช้งานสตูดิโอ (ถอดระบบ Guest Mode) เพื่อให้ทุกผลงานและแบบร่าง VFX ได้รับการผูกกับบัญชีผู้ใช้และซิงค์อย่างปลอดภัย
  - ระบบจดจำชื่อผู้ใช้ (Remember Me) บนอุปกรณ์เพื่อความสะดวกในการเข้าใช้งานครั้งต่อไป
  - ปุ่มเปิด/ปิดการมองเห็นรหัสผ่าน (Password Visibility) ทั้งหน้าเข้าสู่ระบบและสมัครสมาชิก
  - ระบบตรวจสอบความถูกต้องและเช็กความตรงกันของรหัสผ่านแบบเรียลไทม์ พร้อมกล่องแจ้งเตือนข้อผิดพลาดที่ชัดเจน

- ☁️ **ระบบคลาวด์สตูดิโออัตโนมัติ (Automated Cloud Sync)**:
  - เชื่อมโยงและบันทึกแบบร่าง VFX ขึ้นระบบคลาวด์อัตโนมัติในเบื้องหลัง
  - ถอดเมนูตั้งค่าเซิร์ฟเวอร์และข้อมูลทางเทคนิคออกจากหน้าจอทั้งหมด เพื่อความปลอดภัยและภาพลักษณ์ที่ดูเป็นมืออาชีพ
  - ป้ายสถานะระบบคลาวด์แบบมินิมอล พร้อมปุ่มรีเฟรชตรวจสอบสถานะการเชื่อมต่อ

- 🚀 **ระบบซิงค์อัปเดตอัตโนมัติ (CI/CD Auto-Deploy)**:
  - เชื่อมโยงระบบเซิร์ฟเวอร์เข้ากับ GitHub อัตโนมัติ ทุกครั้งที่มีการปล่อยเวอร์ชันใหม่ ระบบจะซิงค์ข้อมูลและรีสตาร์ทตัวเองเบื้องหลังทันทีโดยที่ผู้ใช้ไม่ต้องดำเนินการใดๆ

- 📱 **รองรับการใช้งานข้ามแพลตฟอร์ม (Cross-Platform Ready)**:
  - ทำงานได้อย่างสมบูรณ์แบบทั้งบนสมาร์ตโฟนระบบ Android (APK) และคอมพิวเตอร์ Windows (.exe)
  - ปรับปรุงประสิทธิภาพการเชื่อมต่อเครือข่ายบนมือถือให้เสถียรและราบรื่น
