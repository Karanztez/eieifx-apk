# บันทึกการอัปเดต eieiFX

## เก็บรายละเอียด GLB ด้วยกล่องปรับตามรูปทรง

- เก็บตัวอย่างพื้นผิวละเอียด 64 ช่องตามด้านยาว โดยไม่ลดความละเอียดทั้งตัวเมื่อกล่องเต็ม
- แบ่งกล่องเฉพาะบริเวณที่คลุมพื้นที่เกิน เพื่อเก็บขอบและส่วนเล็กได้มากขึ้น
- หมุนกล่องตามแนวส่วนประกอบเมื่อแนบรูปทรงได้ดีกว่า และส่งมุมหมุนไป Blockbench
- คงงบสูงสุด 1024 กล่อง และเฉลี่ยสีเฉพาะในแต่ละกล่อง
- ต้องนำเข้า GLB ใหม่เพื่อสร้างรายละเอียดด้วยตัวแปลงใหม่ ร่างเก่าไม่ถูกแก้ทับ
