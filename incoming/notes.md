# บันทึกการอัปเดต eieiFX (Release Notes)

## 🌟 เวอร์ชันล่าสุด (1.0.177)

### ✨ ไฮไลท์การอัปเดตล่าสุด

- 🧠 **Local Model Forge ใหม่ทั้งระบบ**: สร้างโมเดลในเครื่องโดยไม่ใช้ Gemini, API Key หรือบริการ AI ภายนอก คำสั่งและภาพจึงไม่ถูกส่งออกจากอุปกรณ์
- 🧰 **โมเดลสำเร็จรูปพร้อมใช้**: มีคลังพิมพ์เขียวและปุ่มลัดสำหรับมังกร เมคา ปราสาท ช้างศึก ยานบิน และฟีนิกซ์ พร้อมรายละเอียดผิว ข้อต่อ สี และไฟล์ Blockbench
- 🖼️ **Image-to-Model ไม่หายอีก**: อ่านสี สัดส่วน และ silhouette จากพิกเซลจริง หากระบุชนิดวัตถุไม่ได้จะสร้าง voxel sculpture ตามรูปทรงภาพแทนการเดาเป็นโมเดลทั่วไป
- 📐 **Geometry Finisher**: จัดกึ่งกลาง ถ่วงพื้น จำกัดขนาด ตรวจตัวเลข เติมดวงตาและชิ้นตกแต่ง ก่อนสร้าง Cubes, Low-Poly, Texture Atlas และ `.bbmodel`
- ✨ **Forge Console ดีไซน์ใหม่**: แสดงขั้น Intent → Blueprint → Geometry → Validate พร้อมสถานะ Offline • Private • No API
